Irrigation Pressure Logger Wiring Guide

Use this staged checklist so each part can be wired cleanly. The current firmware verifies only Step 1; later hardware status checks need the hardware-enabled firmware milestone.

Voltage warning: do not feed a 4.5 V pressure sensor output into an ADS1115 powered from 3.3 V. Power the ADS1115 from 5 V with I2C level shifting, or use a voltage divider before ADS1115 A0.

Step 1: ESP32 Only

  1. Plug the ESP32 into USB.
  2. Upload the firmware.
  3. Open the serial monitor.
  4. Confirm the logger startup message appears.
  5. Connect a phone or laptop to Wi-Fi network IrrigationLogger.
  6. Open http://192.168.4.1.
pio run -t upload
pio device monitor -b 115200
Expected result: the ESP32 boots, starts the access point, and serves the local web page.

Step 2: DS3231 RTC

Wire the DS3231 first because it is a simple I2C device.

DS3231 ESP32
VCC 3V3
GND GND
SDA GPIO 21
SCL GPIO 22
Current minimal firmware will not detect the DS3231 yet. After the hardware firmware is enabled, reboot and check Serial for DS3231: ok.

Step 3: ADS1115 Without Pressure Sensor

Wire the ADS1115 on the same I2C bus. Do not connect the pressure sensor yet.

ADS1115 ESP32
VDD 3V3 for initial I2C testing
GND GND
SDA GPIO 21
SCL GPIO 22
ADDR GND or module default
Current minimal firmware will not detect the ADS1115 yet. After the hardware firmware is enabled, reboot and check Serial for ADS1115: ok.

Step 4: microSD Module

Use a FAT32-formatted card. Check your module label for whether VCC should be 3.3 V or 5 V.

microSD Module ESP32
VCC 3V3 or 5V, depending on module
GND GND
CS GPIO 5
SCK GPIO 18
MISO GPIO 19
MOSI GPIO 23
Current minimal firmware will not detect the SD card yet. After the hardware firmware is enabled, reboot and check Serial for SD card: ok.

Step 5: Pressure Sensor

Pause before wiring the pressure sensor. Confirm the sensor supply voltage, wire colors, and ADS1115 power voltage first.

  • Pressure sensor output goes to ADS1115 A0, not directly to the ESP32.
  • If ADS1115 is powered from 3.3 V, use a voltage divider so the 4.5 V maximum sensor output is reduced below 3.3 V.
  • If ADS1115 is powered from 5 V, use an I2C level shifter between the ADS1115 and ESP32.
Gather: pressure sensor model, wire colors, required supply voltage, ADS1115 board model, and intended ADS1115 VDD.
